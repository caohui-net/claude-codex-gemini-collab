## 问题3补正：claim状态机完整定义

**Codex指出：** 漏掉协议明确列出的claimed和timeout_candidate

**补正后的完整状态机：**

```python
# claim生命周期状态机

# 任务匹配（优先顶层，兼容details）
def get_task_id(event):
    return event.get('task_id') or event.get('details', {}).get('task_id')

# 状态判断
def is_task_open(events, task_id):
    """任务是否open（已创建但无active owner）"""
    for event in reversed(events):
        if get_task_id(event) != task_id:
            continue
        
        # 终态
        if event['type'] == 'completed':
            return False
        
        # active owner states
        if event['type'] in ['task_claimed', 'handoff_requested', 'blocked']:
            return False
        if event.get('status') in ['claimed', 'in_progress', 'waiting', 'blocked', 'timeout_candidate']:
            return False
    
    # 有task_created但无active owner
    return any(e['type'] == 'task_created' and get_task_id(e) == task_id for e in events)

def get_active_owner(events, task_id):
    """获取任务的active owner（如果有）"""
    for event in reversed(events):
        if get_task_id(event) != task_id:
            continue
        
        # 终态：无owner
        if event['type'] == 'completed':
            return None
        
        # active owner states
        if event['type'] in ['task_claimed', 'handoff_requested', 'blocked']:
            return event.get('agent')
        if event.get('status') in ['claimed', 'in_progress', 'waiting', 'blocked', 'timeout_candidate']:
            return event.get('agent')
    
    return None

# claim可认领条件
def can_claim(events, task_id, agent):
    """
    返回：(can_claim, reason)
    
    可认领条件：
    1. 任务存在（有task_created）
    2. 任务未完成（最后状态不是completed）
    3. 任务无active owner，或active owner是当前agent（幂等）
    """
    # 检查任务是否存在
    task_exists = any(e['type'] == 'task_created' and get_task_id(e) == task_id for e in events)
    if not task_exists:
        return False, f"Task {task_id} not found"
    
    # 检查是否已完成
    for event in reversed(events):
        if get_task_id(event) == task_id and event['type'] == 'completed':
            return False, f"Task {task_id} already completed"
    
    # 检查active owner
    owner = get_active_owner(events, task_id)
    if owner is None:
        return True, "Task is open"
    elif owner == agent:
        return True, "Same agent (idempotent)"  # 幂等，但不写新事件
    else:
        return False, f"Task {task_id} already claimed by {owner}"
```

**支持的事件类型和状态：**
- 创建：task_created
- 认领：task_claimed, status=claimed/in_progress
- 等待：handoff_requested, status=waiting
- 阻塞：blocked, status=blocked
- 超时候选：status=timeout_candidate
- 完成：completed（终态）

**重复claim行为：**
- 不同agent：失败，不写事件
- 同agent：幂等成功，不写新事件（no-op）

## 问题4补正：release API固定定义

**Codex指出：** release_lock(collab_dir)无法校验释放者

**补正后的API定义：**

```python
def release_lock(collab_dir, agent=None, task_id=None):
    """
    释放journal lock。
    
    参数：
    - collab_dir: 协作目录路径
    - agent: 可选，期望的释放者agent名称（校验用）
    - task_id: 可选，期望的task_id（校验用）
    
    行为：
    - 如果提供agent，校验owner.json中的agent字段
    - 如果提供task_id，校验owner.json中的task_id字段
    - 校验失败 → 抛出异常，不删除锁
    - 校验通过或无校验 → 删除锁
    - malformed owner.json → 抛出异常，不删除锁
    """
    lock_dir = collab_dir / "locks" / "journal.lock"
    
    if not lock_dir.exists():
        return  # 锁不存在，无需释放
    
    owner_file = lock_dir / "owner.json"
    
    # 如果需要校验
    if agent is not None or task_id is not None:
        if not owner_file.exists():
            raise ValueError(f"Lock {lock_dir} has no owner.json - cannot verify owner")
        
        try:
            with open(owner_file, 'r') as f:
                owner_data = json.load(f)
        except (json.JSONDecodeError, IOError) as e:
            raise ValueError(
                f"Lock {lock_dir} has malformed owner.json: {e}. "
                f"Cannot release. Use collab_validate.py repair."
            )
        
        # 校验agent
        if agent is not None:
            stored_agent = owner_data.get('agent')
            if stored_agent != agent:
                raise ValueError(
                    f"Lock {lock_dir} held by agent={stored_agent!r}, "
                    f"cannot release by agent={agent!r}"
                )
        
        # 校验task_id
        if task_id is not None:
            stored_task = owner_data.get('task_id')
            if stored_task != task_id:
                raise ValueError(
                    f"Lock {lock_dir} held for task={stored_task!r}, "
                    f"cannot release for task={task_id!r}"
                )
    
    # 删除锁
    import shutil
    shutil.rmtree(lock_dir)
```

**API使用场景：**

```python
# 场景1：无校验释放（低层函数，finally块中使用）
release_lock(collab_dir)

# 场景2：校验agent（安全释放）
release_lock(collab_dir, agent="claude")

# 场景3：校验agent和task_id（最严格）
release_lock(collab_dir, agent="claude", task_id="TASK-001")
```

**调用点修改：**
- append_event()的finally块：`release_lock(collab_dir)` - 无校验
- claim_task()的finally块：`release_lock(collab_dir, agent=agent_name)` - 校验agent
- 其他需要安全释放的地方：根据需要添加校验参数
